# Student Productivity Dashboard

## Overview
The Student Productivity Dashboard is a simple data analytics project built using Python and Streamlit.  
It helps analyze student productivity based on study hours, attendance, assignment completion, sleep hours, and screen time.

This dashboard provides interactive charts and insights to understand student performance and daily habits.

---

## Features
- View student productivity dataset
- Track average study hours
- Track attendance performance
- Analyze productivity score
- Compare study hours vs productivity
- Visualize sleep hours vs productivity
- Interactive charts and dashboard

---

## Technologies Used
- Python
- Streamlit
- Pandas
- Matplotlib
- Plotly
- VS Code
